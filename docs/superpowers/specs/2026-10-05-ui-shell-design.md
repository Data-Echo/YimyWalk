# YimyWalk 主菜单与分层设置界面设计

日期：2026-10-05  
范围：M4 UI 最小可用切片

## 目标

把当前单层、按钮堆叠的 ManagerForm 改成一个可持续扩展的主菜单窗口，同时保持已有桌宠模拟、窗口渲染、角色扫描和设置存储逻辑可复用。

用户启动 YimyWalk 后看到普通 Windows 桌面窗口。窗口有一个普通任务栏按钮，用户可以通过任务栏按钮切回主菜单。主菜单打开后默认显示总览封面；桌宠仍在后台活动，主菜单不是桌宠渲染窗口。

本轮优先完成可用的信息架构和真实控件绑定，不加入动画导航、主题编辑器、复杂图表、在线内容或新的桌面权限。

## 已确认的交互原则

- 视觉方向使用高对比、圆角和彩色状态卡：深色文字、奶油色内容区、黄色侧栏、珊瑚色选中态、青绿色开关。
- 左侧导航固定，右侧内容按页面切换。
- 总览是封面页。
- 桌宠管理当前运行中的单只实例：实例列表、活动状态、单只设置和角色预览。
- 选中桌宠时只展示对应角色的 idle1 单帧，不展示完整九宫格 sprite.png。
- 角色管理角色包和角色默认资料。角色预览同样使用单帧。
- 互动保存全局默认和通用规则。
- 桌宠页的设置只影响当前实例。
- 单只桌宠的布尔设置采用三态：跟随全局、强制开启、强制关闭。
- 主入口是普通任务栏窗口，不依赖通知区域左键作为主入口；本轮不增加 Windows 通知。已有托盘能力是否最终移除不作为 UI 壳体的前置条件，迁移期间可保留兼容入口。

## 页面结构

### 总览

总览是启动后的默认页面，提供：

- 当前活动桌宠数量和待创建数量；
- 当前选中角色的单帧预览；
- 快速创建、隐藏/恢复、暂停/继续和一键清空；
- 全局互动状态摘要；
- 角色刷新状态和设置恢复/保存状态。

总览不复制所有设置控件，详细设置通过左侧导航进入。

### 桌宠

桌宠页分为实例列表和选中实例详情：

- 列表显示实例标识、角色名、当前位置/状态摘要、活跃度和活动指示；
- 选择实例后，详情卡显示角色名称、实例状态和 idle1 单帧；
- 活动参数至少包括是否喜欢走动、活跃度和该实例的自动气泡开关；
- 每个覆盖控件显示当前来源：跟随全局、强制开启或强制关闭；
- 提供恢复跟随互动默认值操作；
- 提供创建指定数量、删除当前实例和清空全部等已有业务入口；
- 没有选中实例时，详情区显示空状态，不显示无效控件。

本轮的单只设置先作用于当前运行实例。实例身份和局部覆盖的跨重启持久化另列为后续任务，避免在没有实例存档协议时伪造永久保存。

### 角色

角色页面向角色定义而不是运行实例：

- 卡片或列表显示角色名称、角色 ID、是否有效和默认活动参数；
- 选中角色后显示 idle1 单帧和基础信息；
- 提供刷新角色目录、打开角色目录和查看校验失败摘要；
- 通过明确的“设为下次创建角色”操作保存下次创建默认角色；仅浏览和预览角色不会改变该默认值；
- 只读显示角色配置来源；不在本轮提供完整绘图或素材编辑器。

### 互动

互动页保存全局默认：

- 默认自动气泡；
- 现有虚拟食物创建入口；
- 默认应用切换反馈；
- 默认活跃度；
- 饥饿增长开关和增长倍率；
- 全局静音/对话频率等已有能力可在对应数据已存在时接入。

新建桌宠继承互动默认。已有实例只有在其局部设置为跟随全局时才随默认变化。

### 设置

设置页承载应用级选项：

- 显示缩放；
- 窗口顶部落脚；
- 首选显示器；
- 已有并且有真实运行行为的实例警告选项；若当前版本没有对应行为，不在界面提供无效控件；
- 设置恢复/保存诊断。

设置页不重复呈现单只桌宠的覆盖选项。

## 实现边界

### UI 壳体

ManagerForm 保留为普通 WinForms 窗口，但从单一 FlowLayoutPanel 改为固定侧栏加内容宿主。每个页面使用独立 UserControl，页面只负责展示和发出用户意图，不直接操作文件、窗口句柄或 Core 内部字段。

建议页面组件：

- OverviewPage
- PetsPage
- CharactersPage
- InteractionsPage
- SettingsPage

ManagerForm 负责导航、窗口尺寸、主题资源、页面缓存和生命周期；AppHost 提供最小的业务门面，例如创建/删除实例、读取角色目录、更新全局设置和保存设置。

### 任务栏与生命周期

主菜单窗口设置为 ShowInTaskbar = true，启动时显示总览。最小化只影响主菜单，不隐藏桌宠。为保留桌宠后台运行和任务栏恢复入口，本轮将窗口右上角关闭动作解释为“最小化主菜单并继续运行”，通过主菜单中的明确“退出 YimyWalk”动作结束宿主；任务栏按钮始终可用于恢复窗口。

现有 TrayIconHost 不作为新 UI 的主要入口。本轮不引入通知气泡；是否删除托盘图标需在桌面回归验证后单独决定。

### 角色单帧预览

预览使用 CharacterDefinition 已解码的 RGBA 帧，索引 0 对应 idle1。App 层将该帧转换成现有 FrameSurfaceCache 可用的绘制资源；不得把整张九宫格当作预览图缩放显示，也不得在 Core 中引入 WinForms 或 Bitmap。

## 数据与设置

全局设置继续由 SettingsDocument 校验并由 SettingsStore 原子保存。已有字段继续复用，新增字段只有在有真实 UI 与行为闭环时才加入。

单实例覆盖建议使用 App/Core 可测试的数据对象，至少包括：

- WalkOverride：Inherit、Enabled、Disabled；
- ActivityRateOverride：Inherit 或受限的活动等级/倍率；
- DialogueOverride：Inherit、Enabled、Disabled。

覆盖值属于 PetInstance 的可变运行状态，不放入共享 CharacterDefinition。本轮不承诺跨重启恢复单实例覆盖。

## 验证

核心和 UI 逻辑应保持可测试：

- 导航切换不创建重复页面，也不丢失当前选择；
- 全局默认变化只影响跟随全局的实例；
- 强制开启/关闭覆盖不随全局变化；
- 恢复跟随后重新读取全局默认；
- 选择角色后显示 idle1，不是完整精灵图；
- 角色刷新失败时保留旧定义和当前页面状态；
- 主菜单最小化/恢复不改变桌宠运行；
- 退出仍释放桌宠窗口、气泡、虚拟食物和托盘兼容资源。

Windows 桌面 smoke 需要明确记录普通任务栏窗口可见、最小化/恢复、页面切换、实例设置应用和退出清理。未在真实桌面验证的行为继续标记为未验证，不用 Core 测试替代。

## 非目标

- 不切换到 WPF、WinUI 或 WebView；
- 不实现完整角色编辑器；
- 不添加联网、通知中心、自动更新或管理员权限；
- 不在本轮实现真实快捷方式移动/隐藏；
- 不为每只桌宠创建独立管理窗口；
- 不把单实例设置伪装成已经持久化的用户存档。

## 附加约束（2026-10-05 确认后生效）

### 全局默认、全局限制和单实例覆盖

“互动”页面的默认值和运行级限制必须是不同的设置：

- 默认自动气泡是继承来源，可以被单实例的 DialogueOverride 覆盖。
- 现有 SettingsDocument.DialogueEnabled 保留为运行级总限制，界面文案使用“全局允许自动气泡”或“暂停全部自动气泡”。它为 false 时任何实例都不能通过强制开启绕过；恢复后重新按默认值和单实例覆盖求值。
- 本轮不新增完整勿扰系统。没有独立的全局静音字段时，不增加“静音”控件；文字气泡与声音不是同一个状态。
- ExternalEventsEnabled 表示应用切换反馈功能是否启用。关闭时停止专用的前台进程轮询；“本次不显示反馈”只能表示气泡被全局限制或单实例覆盖，不能冒充功能已经关闭。共享的显示器和窗口表面查询不能被误停。

全局默认变化只影响跟随全局的实例。单实例明确开启或关闭时保持独立。每个控件同时显示设置来源和实际生效值，例如“跟随全局 · 当前开启”“自定义 · 活跃度 0.6”“实例设置为开启 · 当前受全局暂停限制”。

角色页把 IdleSecondsMin/Max 和移动参数标为“角色基础行为”，不再另设含糊的“默认活动参数”旋钮。互动页的“活跃度倍率”只影响自主行为决策频率/倾向；关闭主动走动不阻止拖拽、重力下落和落地。

“恢复跟随互动默认值”只清除当前实例的覆盖，不改全局设置，也不影响其他实例。

`SettingsDocument.WarningLimit` 在本轮继续作为已校验的兼容字段保留；当前没有独立的运行时警告行为，因此设置页不显示它，避免把无效控件当成功能。

### 保存和状态反馈

全局设置修改后立即应用，并自动保存。连续滑块调整使用 250–400ms 的合并写入窗口，避免拖动时高频写盘。界面使用四种明确状态：已应用、保存中、已保存、保存失败。运行时应用成功但保存失败时显示“已应用于本次运行，保存失败”，保留用户输入并提供重试。

单实例覆盖只在本次运行中有效，桌宠详情固定显示：“单只设置仅在本次运行中有效，重启后恢复默认。”总览的保存状态明确标注为“全局设置保存状态”，不暗示单实例覆盖已持久化。

### 任务栏、关闭和退出

保留 ShowInTaskbar = true。启动显示总览；从最小化恢复时保留当前页面、选中实例和滚动位置。右上角关闭动作只最小化主菜单，桌宠继续运行，任务栏按钮仍可恢复；界面固定显示“关闭主菜单后，桌宠仍会继续运行。”不使用反复提示框。

主菜单固定提供“退出 YimyWalk”。最小化主菜单、隐藏桌宠、暂停桌宠和退出程序使用独立控件，不互相触发。显式退出和系统注销/关机结束会话路径设置 IsExiting 后绕过关闭转最小化逻辑，取消待创建任务并清理宠物窗口、气泡、虚拟食物、事件订阅、计时器和仍保留的托盘兼容资源。

### 多实例、队列和选择

一键清空先取消 BatchCreationQueue，再删除当前实例；取消、失败和清空期间不得从旧队列继续生成。总览分别显示实际活动数量和待创建数量，所有入口调用同一 AppHost 业务方法和数量限制。

实例列表按稳定 InstanceId 保存选择，不依赖行号。删除选中实例后选择下一只可用实例，否则显示空状态并禁用详情操作。列表更新使用节流和增量刷新，不重建整个列表、不重置滚动、不打断正在编辑的控件，也不逐帧刷新坐标。选中运行实例与下次创建默认角色分开维护，查看实例不能改变下次创建角色。

刷新失败保留旧定义和页面状态。桌宠详情使用实例实际引用的 CharacterDefinition；角色页使用当前目录中的有效定义。两种预览都只使用索引 0 的 idle1，并复用 FrameSurfaceCache 的缓存与释放责任。

### 低保真布局规格

总览和桌宠详情采用同一壳体：

    +------------------+-----------------------------------------------+
    | 200px 侧栏       | 顶部标题 + 页面说明 + 主次操作                 |
    |                  +----------------------+------------------------+
    | 总览             | 列表/状态卡          | 详情/预览/设置         |
    | 桌宠             | 可滚动区域           | 当前选中项             |
    | 角色             |                      |                        |
    | 互动             +----------------------+------------------------+
    | 设置             | 底部保存/运行状态提示                         |
    +------------------+-----------------------------------------------+

- 默认窗口 1120×720，最小窗口 900×580；侧栏宽度 200px。
- 桌宠页列表与详情比例约 56:44；列表和设置区独立滚动，侧栏固定。
- 标题 22px，分组标题 15px，正文 13px，辅助文字 11px；间距使用 8/12/16/24px。
- 主操作使用青绿色填充，危险操作使用文字或边框样式；珊瑚色只用于选中和警示，黄色主要用于侧栏和轻量提示。
- 内容卡默认奶油/白色，不让每张卡都使用高饱和背景；角色预览区域保持最高视觉权重。
- 空状态、错误状态和禁用状态必须有文字；三态控件必须显示“跟随全局/开启/关闭”和实际生效值，不能只靠颜色。
- 使用 WinForms AutoScaleMode.Dpi、可访问的 Tab 顺序和明显键盘焦点；长角色名和中文文案使用可换行/省略策略，不能裁切主要按钮。

本节覆盖旧文档中“启动即显示主菜单、任务栏始终作为主入口、关闭转最小化”的视觉与壳体描述；托盘主入口、隐藏到托盘、稳定实例 ID、200ms 可见刷新和退出清理仍以 2026-10-06 最新生命周期交接为准。
